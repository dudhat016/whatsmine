Highlight gaps, weaknesses, and opportunities in my current product/project.
Suggest specific improvements based on the comparison.
Prioritize suggestions by impact and importance.
Explain why each improvement would be valuable.
Where relevant, provide examples of how competitors approach the same problem.

Important:
Do NOT implement or modify anything.
Do NOT write production code unless it is necessary to explain an improvement.
Do NOT directly change my existing design, code, architecture, or files.
I only want an analysis and actionable improvement plan that I can review before implementation.

Output format:
Competitor Comparison
What Competitors Do Better
My Product/Project Gaps

Recommended Improvements
Priority — High / Medium / Low

Expected Benefit
Suggested Implementation Approach — high-level only, no actual implementation
Base recommendations on concrete observations rather than generic advice. Clearly distinguish between competitor features that are worth considering and features that may not be relevant to my product.
